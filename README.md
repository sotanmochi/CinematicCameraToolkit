# Cinematic Camera Toolkit

## Installation
You can install via Package Manager in UnityEditor.

1. Open the Package Manager window
2. Click the + button and select "Add package from git URL"
3. Enter: `https://github.com/sotanmochi/CinematicCameraToolkit.git?path=src/CinematicCameraToolkit/Packages/CinematicCameraToolkit#0.1.0`

You can also install via editing Packages/manifest.json directly.
```
// Packages/manifest.json
{
  "dependencies": {
    ...
    "jp.sotanmochi.cinematic-camera-toolkit": "https://github.com/sotanmochi/CinematicCameraToolkit.git?path=src/CinematicCameraToolkit/Packages/CinematicCameraToolkit#0.1.0",
    ...
  }
}
```
